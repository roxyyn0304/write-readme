## 📊 质量评分

### 评分标准（每项10分，满分40分）

1. **结构完整性**（10分）
   - 包含所有必要章节：5分
   - 章节顺序合理：5分

2. **内容质量**（10分）
   - 一句话描述清晰：5分
   - 功能描述具体：5分

3. **格式规范**（10分）
   - 功能用表格展示：5分
   - 命令在代码块内：5分

4. **用户体验**（10分）
   - 快速开始简单：5分
   - 有截图展示：5分

### 评分结果
- **40分**：优秀，无需修改
- **30-39分**：良好，可选优化
- **20-29分**：一般，建议优化
- **<20分**：较差，需要重写

## 🚀 自动化检查脚本

### PowerShell 脚本
```powershell
# 检查README质量
function Test-ReadmeQuality {
    param([string]$Path)
    
    $issues = @()
    
    # 检查文件存在
    if (-not (Test-Path "$Path\README.md")) {
        $issues += "缺少 README.md"
    }
    if (-not (Test-Path "$Path\README_EN.md")) {
        $issues += "缺少 README_EN.md"
    }
    if (-not (Test-Path "$Path\LICENSE")) {
        $issues += "缺少 LICENSE"
    }
    
    # 检查内容
    $content = Get-Content "$Path\README.md" -Raw
    
    if ($content -notmatch "🌐.*English.*简体中文") {
        $issues += "缺少语言切换链接"
    }
    
    if ($content -match "TODO|xxx|占位符") {
        $issues += "包含占位符"
    }
    
    return $issues
}
```

### 使用示例
```powershell
# 检查当前目录
$issues = Test-ReadmeQuality -Path "."
if ($issues.Count -eq 0) {
    Write-Host "✅ README 质量检查通过" -ForegroundColor Green
} else {
    Write-Host "❌ 发现以下问题：" -ForegroundColor Red
    $issues | ForEach-Object { Write-Host "  - $_" }
}
```
