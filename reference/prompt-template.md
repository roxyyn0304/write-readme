# Prompt 模板集

给其他 AI 写 README 用的提示词模板。

---

## 模板 1：基础版（填空式）

```
请为我的项目写 README.md + README_EN.md：

项目名称：
项目简介：（一句话：做什么 + 给谁用）
技术栈：
Fork 来源：（原创项目 / Fork 自 xxx）
核心功能：（列出 3-5 个）
安装方式：（下载安装 / 源码编译 / 包管理器）
环境要求：
目标用户：

格式要求：
- 功能特性用分组表格
- 命令用代码块
- 标题用 emoji + 中文
- 快速开始从最简单方式写起
- 中文 README.md + 英文 README_EN.md
```

---

## 模板 2：详细版（给具体指令）

```
请为以下项目生成专业的 README 文档：

【项目信息】
- 名称：[项目名]
- 类型：[CLI工具/库/Android模块/Web应用/其他]
- 语言：[Rust/TypeScript/Python/Java/Kotlin/其他]
- 框架：[如果有]
- Fork：[是/否，原项目链接]
- License：[MIT/GPL/Apache/其他]

【核心功能】
1. [功能1]：[简要说明]
2. [功能2]：[简要说明]
3. [功能3]：[简要说明]

【安装方式】
- [ ] 下载 Release 包
- [ ] 包管理器安装（npm/pip/cargo）
- [ ] 源码编译

【输出要求】
1. README.md（中文）
2. README_EN.md（英文）
3. 保留 emoji 格式
4. 功能用表格，不用段落
5. 快速开始要能「复制粘贴就能跑」
```

---

## 模板 3：极简版（快速生成）

```
帮我写个 README，项目是 [一句话描述]。
功能：[功能1]、[功能2]、[功能3]
技术栈：[语言/框架]
安装：[方式]
```

---

## 模板 4：重写版（优化现有 README）

```
请帮我优化这个项目的 README：

[粘贴现有 README 内容]

问题：
- [ ] 结构混乱
- [ ] 缺少截图
- [ ] 功能没分组
- [ ] 快速开始太复杂
- [ ] 其他：xxx

请按照以下标准重写：
1. 功能特性用分组表格
2. 快速开始从最简单方式开始
3. 标题用 emoji + 中文
4. 保持简洁，每句话都有信息量
```

---

## 模板 5：批量版（多项目）

```
请为以下 3 个项目分别写 README：

项目1：
- 名称：
- 简介：
- 技术栈：

项目2：
- 名称：
- 简介：
- 技术栈：

项目3：
- 名称：
- 简介：
- 技术栈：

每个项目输出 README.md + README_EN.md，格式统一。
```
